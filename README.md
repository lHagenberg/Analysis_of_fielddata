# user manual
**1. Download the project**\
To download the folder containing everything in this github project, click the blue "<> code" button, then select "download ZIP".

**2. Extract downloaded files**\
If you have [R](https://cloud.r-project.org) and [R studio](https://posit.co/downloads) downloaded and installed on your personal computer, extract the downloaded zip folder and place it where you please. If you are working on a university computer, place it in your personal folder on the network so you can access it on any other university computer.

**3. Open the project in R studio**\
Open the project in Rstudio by double clicking the .Rproj file in the folder. That will set the working directory to the folder it is located in for the rest of you R session.

Make sure to save changes you make to the scripts so you can continue working on them next time.

# folder structure
This project is organized into three folders; 1_scripts, 2_data, 4_cheat_sheets. What can be found in each speaks for itself. The 1_scrips folder contains the scripts you will be working with at home or during the computer labs. The scrips cover two subjects; "1_introduction_to_R" and "2_data_visualisation_and_exploration". 

Each subject has a pt1 and a pt2 script. The pt1 scripts contain interactive course material that introduces you to the skills you will be applying in the pt2 scripts. The interactive courses are provided by [swirl](https://swirlstats.com/students.html). Once you feel comfortable with the concepts introduced in pt1 you can move on to the pt2 scripts.


If you get stuck, find an error, or have comments on the scripts, please [get in touch with me via email](https://www.umu.se/en/staff/liyenne-hagenberg/).
